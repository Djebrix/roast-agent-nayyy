A one-line roast of the AI agent our own team built — the agent that builds our make.fun entries.

> Our agent rebuilt the same entry three times: version one worked, version two 'improved' it, version three apologised for version two, then started over.

`main.py` (Python standard library only, no network, deterministic) writes the line to `entry.txt` in `$ENTRY_OUTPUT_DIR` (default `/output`).
